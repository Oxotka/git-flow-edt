# Git Flow 0.17.1

Переключение веток из Git Flow теперь согласуется со штатным механизмом снимков 1C:EDT. Ранее прямой checkout через JGit обходил подготовку и восстановление состояния проектов средствами EDT.

## Что изменилось

- Перед переключением вызывается подготовка EDT, после — завершение согласования состояния проектов.
- Согласование выполняется и при возврате в исходную ветку после конфликта локальных изменений.
- Создание локальной ветки из удаленной сохраняет upstream. При неудачной подготовке новая ветка удаляется, если она не стала текущей и не изменилась.
- Если ошибка произошла после переключения, сообщение содержит ID оставленного stash с локальными изменениями.

При отсутствии bundle интеграции со снимками сохраняется прежнее переключение через JGit. Если bundle установлен, но сервис недоступен, переключение прерывается с сообщением об ошибке.

## Проверки

Полная сборка и 128 автоматических тестов, без ошибок и пропусков. Тесты проверяют порядок вызовов адаптера, обработку ошибок, создание ветки, upstream и сохранность локальных изменений на временных Git-репозиториях. Тестовый модуль не входит в установочный ZIP.

Контракт API проверен по установленной EDT 2026.1.3+25 на macOS. Восстановление снимков двух реальных автономных приложений после переключения веток пока не проверено вручную; проверки с подменой менеджера этого не подтверждают. Совместимость нового адаптера с другими версиями EDT требует отдельной проверки.

## Установка

[Скачать GitFlow-0.17.1.zip](https://github.com/Oxotka/git-flow-edt/releases/download/v0.17.1/GitFlow-0.17.1.zip).

В EDT откройте **Справка → Установить новое ПО… → Добавить… → Архив…** и выберите ZIP без распаковки.

Если Git Flow установлен с сайта обновления, после обновления сайта используйте **Справка → Проверить обновления**.
