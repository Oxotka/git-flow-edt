# Git Flow 0.17.2

Заменяет отозванный выпуск 0.17.1. Если установлена версия 0.17.1, обновитесь до 0.17.2.

Возвращено переключение веток через JGit без дополнительного согласования
со снимками EDT. Согласование, добавленное в 0.17.1, по пользовательской
проверке замедляло переключение и не устраняло повторное отображение изменений.

Сохранены прежняя защита staged, unstaged и untracked изменений,
восстановление исходной ветки после конфликта и обновление проектов после
checkout. Настройки информационных баз и автономных серверов не меняются.

Причина повторного отображения изменений пока не установлена. Этот выпуск
убирает дополнительную работу при переключении, но не заявляет исправление
синхронизации баз. Фактическую скорость нужно проверить на пользовательском проекте.

## Проверки

Чистая сборка и 118 автоматических тестов без ошибок и пропусков. Установочный
ZIP проверен; удаленный адаптер снимков и тестовые библиотеки в него не входят.

Git Flow проверен в **1C:EDT 2026.1.3 на Windows и macOS**.
Ранее также проверен в EDT 2025.2.6 на Windows.

## Установка

[Скачать GitFlow-0.17.2.zip](https://github.com/Oxotka/git-flow-edt/releases/download/v0.17.2/GitFlow-0.17.2.zip).

В EDT откройте **Справка → Установить новое ПО… → Добавить… → Архив…**
и выберите ZIP без распаковки. При установке с сайта обновления используйте
**Справка → Проверить обновления** после обновления сайта.
