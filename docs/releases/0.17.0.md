# Git Flow 0.17.0

Выпуск ускоряет автоматическую подготовку большого числа файлов перед коммитом и упрощает внутреннюю логику панели.

## Что изменилось

- **Быстрее подготовка изменений.** Вся показанная выборка подготавливается целиком вместо пачек по 32 файла. Файлы вне выборки не добавляются. В синтетическом тесте подготовка 800 файлов заняла 0,072 с вместо 0,404 с; это замер самой подготовки на macOS с прогретым кешем, без обновления UI и сетевых операций.
- **Понятнее статус операции.** В панели показывается переданное название этапа или текущий файл.
- **Меньше повторных поисков иконок.** Отсутствующие иконки объектов 1С запоминаются до закрытия панели; текстовые подписи сохраняются.
- **Упрощена внутренняя логика.** Подписи объектов 1С, поиск и загрузка истории выделены из основного представления. Убрано дублирование построения списков изменений и подготовки истории.

При отмене до начала подготовки индекс не меняется. При отмене во время подготовки выбранные файлы подготавливаются, а создание коммита не продолжается.

## Проверки

118 автоматических тестов; отдельно выполнен синтетический прогон на 800, 1000 и 5000 файлах с проверками состава индекса и сохранности остальных изменений. Изменения также прошли локальную проверку в предварительной сборке 0.16.3.

Ранее подтвержденные среды: EDT 2025.2.6 на Windows и EDT 2026.1.3 на macOS. Совместимость с EDT 2026.2 пока не проверена. Тесты и бенчмарк не входят в установочный архив.

## Установка

[Скачать GitFlow-0.17.0.zip](https://github.com/Oxotka/git-flow-edt/releases/download/v0.17.0/GitFlow-0.17.0.zip).

В EDT откройте **Справка → Установить новое ПО… → Добавить… → Архив…** и выберите ZIP без распаковки.

Если Git Flow установлен с сайта обновления, после публикации выпуска и обновления сайта используйте **Справка → Проверить обновления**.
